# Tipografías de Dialo

Archivos WOFF2 sin modificaciones, distribuidos con sus licencias SIL Open Font License adjuntas.

- @fontsource-variable/geist 5.3.0: https://www.npmjs.com/package/@fontsource-variable/geist/v/5.3.0
- @fontsource-variable/schibsted-grotesk 5.3.0: https://www.npmjs.com/package/@fontsource-variable/schibsted-grotesk/v/5.3.0
- @fontsource-variable/archivo 5.3.0: https://www.npmjs.com/package/@fontsource-variable/archivo/v/5.3.0

La UI usa Geist y Schibsted Grotesk. Archivo mantiene los ejes de ancho y peso, y su variante cursiva, para la landing. Los subconjuntos se descargan solo cuando los caracteres se necesitan. No requiere paquetes npm en tiempo de ejecución.
